# Professional Color Palettes for Presentations

## Usage Guidelines

- Choose one palette and use it consistently throughout
- Ensure sufficient contrast for accessibility (WCAG AA: 4.5:1)
- Use primary color for headings and emphasis
- Use secondary color for accents and highlights
- Use neutral colors for backgrounds and body text
- Limit to 3-4 main colors maximum

---

## Palette 1: Modern Tech (Dark Theme)

**Best for:** Technology presentations, developer talks, startup pitches

```css
--primary: #e94560;      /* Vibrant red-pink */
--secondary: #0f3460;    /* Deep blue */
--accent: #533483;        /* Purple */
--background: #1a1a2e;    /* Dark navy */
--surface: #16213e;       /* Lighter navy */
--text: #ffffff;          /* White */
--text-muted: #a8a8a8;    /* Light gray */
```

**Use cases:**
- Primary: Headings, call-to-action buttons, key metrics
- Secondary: Subheadings, borders, secondary elements
- Accent: Highlights, special sections, gradients
- Background: Main slide background
- Surface: Cards, containers, code blocks
- Text: Body text, headings
- Text-muted: Captions, metadata, timestamps

## Color Psychology

### Red (#e94560, #ff6b6b, #e76f51)
- **Emotions:** Passion, urgency, excitement
- **Use:** Call-to-action, warnings, emphasis
- **Avoid:** Large areas (can be overwhelming)

### Blue (#0f3460, #0056b3, #0066cc)
- **Emotions:** Trust, professionalism, calm
- **Use:** Corporate, technology, medical
- **Avoid:** Can feel cold if overused

### Green (#2d6a4f, #52b788, #4ecdc4)
- **Emotions:** Growth, balance, nature
- **Use:** Environmental, wellness, success
- **Avoid:** Can feel too casual in formal settings

### Yellow (#ffc107, #ffe66d, #e9c46a, #ffcc00)
- **Emotions:** Optimism, energy, attention
- **Use:** Highlights, warnings, accents
- **Avoid:** Text on white (poor contrast)

### Purple (#533483)
- **Emotions:** Creativity, luxury, wisdom
- **Use:** Creative, premium, innovative
- **Avoid:** Can feel mysterious or unclear

### Orange (#f4a261, #e76f51)
- **Emotions:** Enthusiasm, warmth, confidence
- **Use:** Energetic, friendly, approachable
- **Avoid:** Can feel aggressive in large doses

## Accessibility Guidelines

### Contrast Ratios (WCAG)

- **AA Standard:** 4.5:1 for normal text, 3:1 for large text
- **AAA Standard:** 7:1 for normal text, 4.5:1 for large text

### Testing Contrast

Use online tools to verify contrast:
- WebAIM Contrast Checker
- Colour Contrast Analyser
- Chrome DevTools Accessibility Panel

### Tips for Accessibility

1. Never use light text on light backgrounds
2. Avoid red/green combinations (color blindness)
3. Provide text alternatives for color-coded information
4. Test with grayscale to ensure readability
5. Use color + pattern for data visualization

## Implementation Example

```css
:root {
  /* Choose your palette here */
  --primary: #e94560;
  --secondary: #0f3460;
  --accent: #533483;
  --background: #1a1a2e;
  --surface: #16213e;
  --text: #ffffff;
  --text-muted: #a8a8a8;
}

body {
  background: var(--background);
  color: var(--text);
}

h1, h2, h3 {
  color: var(--primary);
}

.card {
  background: var(--surface);
  border: 1px solid var(--secondary);
}

.highlight {
  color: var(--accent);
}

.muted {
  color: var(--text-muted);
}
```
